## 💻 Running an app

Clone the repository:

```bash
git clone YOUR-REPOSITORY-URL
```

Enter the project folder:

```bash
cd YOUR-PROJECT
```

Install the dependencies:

```bash
npm install
```

And start the app:

```bash
npm start
```

✨ tadaaa — your Electron app should open!
